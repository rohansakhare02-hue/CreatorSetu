# CreatorSetu

CreatorSetu is a full-stack creator management web platform designed to help creators manage tasks and track earnings through a centralized dashboard.

## Features

- Centralized dashboard for task and earnings management
- User authentication using Firebase Authentication
- Persistent data storage with Firebase
- REST API integration for client-server communication
- Backend services built using Node.js and Express.js
- Responsive web interface
- Web application deployment using Firebase Hosting

## Project Architecture

Frontend → REST API → Node.js / Express.js → Firebase

The frontend communicates with backend services through REST APIs. Firebase is used for authentication and persistent data management.

## Installation

1. Clone the repository

git clone YOUR_REPOSITORY_LINK

2. Navigate to the project directory

cd CreatorSetu

3. Install dependencies

npm install

4. Start the server

npm start
